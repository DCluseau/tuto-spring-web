Consider a server-side application for managing articles whose functional specifications are:
→ Each article is defined by its ID, description, brand, and price
→ The application allows adding articles to the database
→ Viewing, updating, and deleting articles
→ Displaying all articles using a pagination system
→ Searching for articles based on a keyword and displaying them

The technical specifications are:

→ Spring Boot 2.6.0 / Spring Data JpaHibernate / Spring MVC / Thymeleaf / Lombok
→ Java 11 / Eclipse or IntelliJ / MariaDB DBMS / Bootstrap
Note: When a version number is missing, ensure you find a version compatible with the indicated version numbers.

There are two roles in the application (Spring Security):
→ ADMIN has access to all application pages
→ USER can view the list of articles
